⚠️ Note on Edge Cases and Scope

The solutions in this repository are specifically tailored for **PRO1 (Introduction to Programming)** and are strictly aligned with the automated evaluator constraints on **Jutge.org**. 

* **Beginner Scope:** Problems are designed for introductory learning, so solutions deliberately stick to the problem requirements rather than exhaustive edge-case handling (e.g., mathematical zero edge cases, type overflow, or unexpected inputs).
* **Strict Evaluation:** Code implementations prioritize passing Jutge's test cases over production-level robustness. If an edge case is intentionally ignored in a solution, it is because Jutge's specifications or test suites do not require it for this level.
